# موقع مطعم حركة - Haraka Restaurant Website 🍕🌯🍔

موقع إلكتروني احترافي لمطعم **حركة** (كريب - بيتزا - شاورما - برجر)، مصمم بأعلى معايير الويب واستجابة الشاشات.

## 🌟 مميزات الموقع:
1. **عرض كل صنف بالكامل (Single Menu Items):** كل وجبة ممثلة بكارت خاص يحتوي على (اسم الوجبة، المكونات، الأحجام والأسعار، وصورة عالية الجودة تعبر عنها).
2. **فلترة المنيو (Categories Filter):** إمكانية التنقل السريع بين أقسام البيتزا، الكريب، المكسات، الشاورما، البرجر والإضافات.
3. **قسم عروض اليوم التفاعلي (Dynamic Offers):** يتيح لآدمن الموقع إضافة عروض جديدة بسهولة وتحديث الأسعار عبر نافذة التحكم المنبثقة.
4. **أرقام الديلفري والواتساب:**
   - **الديلفري للطلبات:** `01111111111`
   - **الواتساب للاستفسارات والطلبات المباشرة:** `01111111112`
5. **عنوان واضح ومصمم بحرفية:** "حي المحطة أمام مطعم البحراوي" مع زر للحصول على الاتجاهات.
6. **عبارات تسويقية فاخرة وتصميم داكن أنيق (Dark Mode Theme)** يتناسب مع هويّة المطاعم العصرية.

## 🚀 طريقة الرفع على جيت هب (GitHub Pages):
1. قم بفك الضغط عن ملف `haraka_restaurant_website.zip`.
2. افتح حسابك على [GitHub](https://github.com) وإنشاء مستودع جديد (New Repository) باسم `haraka-restaurant`.
3. قم برفع جميع الملفات الموجودة داخل مجلد المشروع (`index.html`, مجلد `css`, مجلد `js`, وملف `README.md`).
4. اذهب إلى **Settings** -> **Pages** في مستودع GitHub الخاص بك.
5. تحت قسم **Build and deployment** اختر الفرع `main` ثم اضغط **Save**.
6. سيكون موقعك جاهزاً ومباشراً خلال ثوانٍ!
